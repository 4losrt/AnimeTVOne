# AnimeTVOne

AnimeTVOne is an anime browsing and playback app for Fire TV and Android TV, built with Jetpack Compose and remote-control-first navigation.

## Features

- Home, weekly schedule, and anime catalog
- Favorites and playback history
- Episode selection and player controls
- Remote-control focus navigation for TV
- Cover caching and data-management settings

## AI-assisted development

This project used AI assistance for requirements, interface design, implementation, testing, and documentation. The project maintainer remains responsible for reviewing and publishing all code and functionality.
